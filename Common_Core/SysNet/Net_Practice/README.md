## Description
The Netpractice project is a project designed to teach the student networks, IP addressing, subnet masks, and TCP protocols. It does so through 10 exercises of escalating dificulty in which the student must configure a network to match the directions of the exercise through manipulating ip addresses, subnet masks, and gateways.

## Instructions
This project folder contains 10 json files corresponding to the 10 exercises of the project, obtained from the 'get my config' option in the project portal.

The project portal is launched by downloading and extracting the resource packet from the project webpage, then launching the portal through the `sh run.sh` command. Alternatively, `./netpractice/run.sh` can be used inside the extraction folder. In the portal, the project can be started by entering a 42 username on the 'Training' tab and starting the exercises. Configurations can be validated with the 'check again' button and exported with the 'get my config' button. The submission requires 10 exported json files of network configurations, 1 for each exercise. These json files must be places at the root of the git repository for the project.
