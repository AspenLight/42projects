## Description
This project, born2beroot, aims to create a virtual machine with exact specifications defined in the subject.

## Instructions
the born2beroot virtual machine can be started from the Oracle Virtualbox application. The monitoring.sh file can be run with `sh monitoring.sh`. It runs automatically every 10 minutes. The virtual machine is accessible through port forwarding on port 4242.
